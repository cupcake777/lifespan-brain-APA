# apa-paper-02 main figure 绘图规范

本规范是从 Fig 1 的 7 轮修改（v1 到 v7，2026-10-16）总结出来的，Fig 2–6 和 ED 必须照此执行。
参考实现：`fig1_composite_v7.R`。历次失败版本存放在 `_archive/fig1_iterations/`，可对照查看每条规则针对的问题。

---

## 0. 动手前先做的五件事

1. **列出论证链**。从正文中逐句摘出引用这张图的句子，每一句结论对应一个 panel。说不出"这个 panel 证明哪一句"的，要么删掉，要么并入别的 panel。
   - v1–v4 的失败在于把手头的分析一个个摆上去，图本身不构成论证。v5 起按 §2.1 的句子逐一排 panel，问题才解决。
2. **先规划面积**。整图宽 180 mm、高 170–210 mm。证明核心结论的 panel 占最大面积（Fig 1c 约占半页），其余 panel 按重要性递减。
3. **确认数据口径**。所有数字都必须来自当前这一轮的结果表。核对文件的修改时间，区分刷新后和刷新前的表。图上数字和正文不一致时（例如未校正 OR 与校正 OR），图注必须写明。任何图都不允许出现模拟或示意数据，TOC 也不例外。
4. **先把"论证链 + 面积表"发给作者确认，再动笔**。表里每个 panel 写清楚：证明哪一句、重要性、面积占比、图型、数据来源。Fig 2–4 v1 跳过这一步，结果各 panel 面积平均、重点不突出，返工（10-16）。
5. **面积按结论的分量分配，不按网格平均分配**。"弱相关""只比零分布略高"这类陪衬结论只给小块；标题里的核心结论和代表性例子给大块。Fig 3a 一句小结论占了大块面积，是反例。

## 1. 版式

| 规则 | 反例（之前的版本） |
|---|---|
| 主 panel 放大；次要 panel 并排或叠放在它旁边 | v1 每个 panel 单独画，拼起来大小相同，主次不分 |
| 不要单列"摩天楼"；短列表做成左右两栏 | v4 的富集棒棒糖图拉满整行 |
| 留白不超过 30%；面积要和信息量相称 | v3 的 d 是一条曲线占了半个 panel |
| 只有几个百分比的 panel 不单独存在，数字放进主 panel 或正文 | v3/v4 的累计变化曲线（d）被删除 |
| 两个 panel 共用的图例放在它们下方居中 | v5 的性别图例放在一个 panel 内部 |
| 侧列的 panel 用 `wrap_elements()` 包起来，避免 patchwork 对齐时把绘图区压窄 | v6 的 Venn 和小提琴图被压扁 |

## 2. 图型选择

- **一张主图里尽量用多种图型**：直方图 + rug、散点、曲线带 + 热图、Venn、矩阵、小提琴图。
- **禁用 PPT 式图表**：漏斗图、100% 堆叠横条、只是为了填满空间的粗实心条。
- **表示共享或重叠比例一律用 Venn**。
- **富集要画出对照**：画"条目 × 全部类别"的 OR 矩阵，让读者看到选择性（如 Ribosome 在 C1 为 5.4，在 C2 为 0.4）。不要只列出某一类的显著条目，那样看不出"分化"。
- **不允许单点或单柱的坐标系**：只有一个数值时，要么补上对照组，要么写进正文。
- **效应量用 point-range 或 forest 图**，线条要细；不显著的点用空心、颜色调淡。
- **大面积填色只用于类别色带和热图**。
- **禁用的是 PPT 式粗实心条，不是条形图本身**。每张图最多 2 个条形图 panel，而且类型要不同（如直方图 + 分组条）。不要把所有统计都换成点线图，那样每个 panel 长得一样，同样没有重点（Fig 2–4 v1 的反例）。
- **"观测 vs 零分布"不要只画几个点**：优先画完整分布（QQ 图、t 值分布、逐基因散点），让一个 panel 承载更多维度。
- **机制图用 DNA Features Viewer（python 包 `dna_features_viewer`）按真实坐标画**：转录本、cUTR/aUTR、近端/远端 PAS、变异位置。去掉默认的标签框，自己控制标注。示意图必须承载信息；与数据 panel 重复的纯示意图删除（Fig 4a v1 的反例）。
- **代表性位点用作者 `plot_figure4_dynamic.py` 的风格**：长短 3′UTR 模型 + 按阶段叠放的基因型箱线图（带均值线）+ 分组覆盖度轨道。

## 3. 内容边界

- 主图不放 QC 台账：批次对照表、bridge batch、"pending"等字样。
- 主图不放阴性或 null 结果，也不放稳健性 panel。这些放 ED。
- **除 prenatal / postnatal 外，不定义任何生命阶段**：不写 Infancy、Adolescence 等，也不画阶段色带。
- 需要强调的关键年龄（2 mo、11 y）只给刻度标签加粗、换色，含义写在正文里。
- 解释性语句不放在图上（如"fastest change at GW27"），放到正文或图注。
- TOC 的 forest 图不按人群拆分，性状统一用 EUR GWAS。

## 4. 颜色（语义锁定，全文唯一）

| 语义 | 颜色 |
|---|---|
| C1 / C2 / Shared | `#0072B2` / `#D55E00` / `#009E73` |
| Prenatal / Postnatal | `#E69F00` / `#56B4E9` |
| 性别 Male / Female | `#7A9CC6` / `#D9A5B3` |
| 组学 rug：Transcriptome / Genotype / Proteome | `#8FB9A8` / `#6C7A99` / `#E3B98A` |
| 热图（z-score、OR） | 蓝–粉，`#3B5B92 … #F6F6F6 … #B2456E`。**不要**用紫–绿，也不要用蓝–橙（会和 C1/C2 冲突） |
| 关键年龄刻度 | `#7B3294`，加粗 |

- 鲜艳的颜色只用在点、线、边框上；大面积填充用浅色（color.md 里的 `pal_tint`）。
- 同一个颜色不能在不同的图里表示不同的东西。⚠ `#009E73` 目前在 Fig 1 表示 Shared，在 Fig 4/5 又表示 Amplified 和 APA-only，重画 Fig 4/5 时必须换掉。

## 5. 坐标轴

- **不要把点截断堆在坐标轴边缘**。Fig 1b 现在是线性 0–300，不封顶。
- 用 `coord_cartesian()` 把视野聚焦在信号区，不丢弃数据（例：LOEUF 显示 0.15–2.5，图注说明有 196 个基因在显示范围外）。
- **没有供体的 2 mo–11 y 区间**：画成窄灰带（约占宽度 5%）；曲线在灰带内用虚线连接；热图在灰带内按两端插值，上面叠半透明灰。**不允许留空**。
- 产前段至少占时间轴宽度的 35–40%。
- 孕周按 GW = 40 + age × 52.14 换算，标为 "Gestational week" 或 GW，**不要写 PCW**。

## 6. 标签与文字

- 标签越短越好："APA events"、"C1 genes"、"C1-spec."。
- 同一个信息只标一次（v5 的 Venn 外圈和内圈重复）。
- **不要用长注释 label**：图上只放数字和极短标签（如 "186"、"28%"），阈值、定义、比较说明一律放图注（Fig 3d、Fig 4e v1 的反例）。分面标题不超过 2–3 个词。
- 比较要写明比较对象：用括号加 "Shared vs specific"。
- 统计量太长时分两行：比较对象一行，β 和 FDR 一行。
- 字号：正文 6–7 pt，关键标签加粗，panel 字母 8 pt 粗体小写。
- **出图后逐个检查文字碰撞**：相邻刻度（如 "Birth" 与 "2 mo"）、统计文字与坐标轴、标签与数据点。

## 7. 流程

1. 一张图写一个合成脚本（`figN_composite_vK.R`），开头 `source(00_theme_config.R)`。
2. 先渲染整张 PNG（180 mm 宽，300 dpi），逐个 panel 检查一遍再发给作者。
3. 每改一轮就新建一个版本号，旧版本移到 `_archive/`。
4. 作者确认之后再导出 PDF。
