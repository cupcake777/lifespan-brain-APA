# Module 04: stage-specific apaQTL

`apaqtl/` and `eqtl/` contain the retained stage-specific mapping, preprocessing,
colocalization, mediation, mashr and visualization scripts. Their absolute
production paths and existing working-directory conventions are unchanged.

`apaqtl/qtl_pipe.sh` is included locally and is the default tensorQTL driver used
by `apaqtl/qtl.sh` and `apaqtl/qtl_DS.sh`.
